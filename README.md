#### 🔹 Module 2: Data Types, Variables နှင့် Operators
- **သင်ယူမှု ရည်ရွယ်ချက် (Objective)**: ဒေတာအမျိုးအစားများကို ခွဲခြားသိမြင်ပြီး တွက်ချက်မှုဆိုင်ရာ Operators များကို မှန်ကန်စွာ အသုံးချနိုင်ရန်။
- **သင်ကြားမည့် အကြောင်းအရာများ**:
  1. Variables သတ်မှတ်ခြင်း စည်းမျဉ်းများ (`$name`, CamelCase vs Snake_case)။
  2. Scalar Data Types: `String`, `Integer`, `Float`, `Boolean`။
  3. Compound Data Types: `Array`, `Object`, အထူး Type ဖြစ်သော `NULL`။
  4. Comparison Operators တွင် `==` (Loose) နှင့် `===` (Strict Equality) ကွာခြားချက်။
- **လက်တွေ့ Code နမူနာ**:
  ```php
  <?php
  $productName = "MacBook Pro M3";
  $price = 1999.99;            // Float
  $quantity = 3;               // Integer
  $inStock = true;             // Boolean
  $discountRate = 0.05;        // 5% discount

  $subtotal = $price * $quantity;
  $discountAmount = $subtotal * $discountRate;
  $grandTotal = $subtotal - $discountAmount;

  echo "ပစ္စည်းအမည်: $productName <br>";
  echo "ကျသင့်ငွေ စုစုပေါင်း: $" . number_format($grandTotal, 2) . "<br>";

  // Strict comparison စစ်ဆေးမှု
  $var1 = 100;
  $var2 = "100";
  echo ($var1 === $var2) ? "Type ရော တန်ဖိုးပါ တူသည်" : "Type မတူညီပါ (int vs string)";
  ?>
  ```
- **သိထားသင့်သော Best Practice**:
  - PHP တွင် Bug များ လျော့နည်းစေရန် `==` အစား `===` ကိုသာ အမြဲ ဦးစားပေး အသုံးပြုရမည်။

#### 🔹 Module 3: Control Structures & Modern PHP Expressions
- **သင်ယူမှု ရည်ရွယ်ချက် (Objective)**: ဆုံးဖြတ်ချက်ချမှတ်မှု Logic များ (Conditionals) နှင့် ထပ်ခါတလဲလဲ အလုပ်လုပ်ခြင်း (Loops) များကို ပိုင်နိုင်စေရန်။
- **သင်ကြားမည့် အကြောင်းအရာများ**:
  1. `if`, `else`, `elseif` logic flow များ။
  2. Nested Conditions နှင့် Ternary Operator (`?:`)၊ Null Coalescing Operator (`??`)။
  3. PHP 8 မိတ်ဆက်: `switch` ထက် ပိုမိုမြန်ဆန်ပြီး type-safe ဖြစ်သော `match` expression။
  4. `for`, `while`, `do-while` နှင့် array များအတွက် `foreach` loop။
- **လက်တွေ့ Code နမူနာ**:
  ```php
  <?php
  // 1. Match Expression (PHP 8 Feature)
  $userRole = "editor";

  $dashboardAccess = match ($userRole) {
      "admin" => "Admin Panel သို့ ဝင်ရောက်ခွင့် ရှိသည် (Full Access)",
      "editor" => "Post များကို ပြင်ဆင်ဖျက်ပစ်ခွင့် ရှိသည် (Limited Access)",
      "subscriber" => "ဖတ်ရှုခွင့်သာ ရှိသည် (Read Only)",
      default => "ဧည့်သည်ဖြစ်ပါသည်၊ အကောင့်ဖွင့်ပါ",
  };
  echo "လုပ်ပိုင်ခွင့် အဆင့်: $dashboardAccess <br><br>";

  // 2. Foreach Loop ဖြင့် ဈေးနှုန်းစာရင်း ထုတ်ပြခြင်း
  $exchangeRates = ["USD" => 3800, "SGD" => 2900, "THB" => 108];
  echo "<strong>ငွေလဲလှယ်နှုန်းများ:</strong><br>";
  foreach ($exchangeRates as $currency => $rate) {
      echo "1 $currency = $rate မြန်မာကျပ်<br>";
  }
  ?>
  ```
- **လက်တွေ့ အိမ်စာ (Lab Exercise)**:
  - ရမှတ် (Score) ပေါ်မူတည်၍ Grade (A, B, C, D, Fail) ခွဲခြားပေးသည့် စနစ်နှင့် ၁ မှ ၁၀၀ အတွင်းရှိ စုံကိန်း (Even numbers) များကိုသာ ထုတ်ပြသည့် Loop တစ်ခု ရေးသားပါ။

#### 🔹 Module 4: Arrays & Core Built-in Functions
- **သင်ယူမှု ရည်ရွယ်ချက် (Objective)**: စာရင်းဇယား အချက်အလက်များကို Array အမျိုးမျိုးဖြင့် စီမံခန့်ခွဲတတ်ပြီး Built-in functions များကို ကျွမ်းကျင်စွာ သုံးစွဲနိုင်ရန်။

- **CSRF Protection နမူနာ**:
  ```php
  <?php
  session_start();

  // 1. Token ထုတ်ပေးခြင်း (Form ထဲတွင် Hidden ထည့်ရန်)
  function generateCsrfToken(): string {
      if (empty($_SESSION['csrf_token'])) {
          $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
      }
      return $_SESSION['csrf_token'];
  }

  // 2. Token စစ်ဆေးခြင်း (Form Submit ရောက်လာချိန်)
  function validateCsrfToken(?string $submittedToken): bool {
      return isset($_SESSION['csrf_token']) && hash_equals($_SESSION['csrf_token'], $submittedToken ?? '');
  }

  // စစ်ဆေးမှု Logic
  if ($_SERVER["REQUEST_METHOD"] === "POST") {
      if (!validateCsrfToken($_POST["csrf_token"] ?? null)) {
          http_response_code(403);
          die("လုံခြုံရေးချိုးဖောက်မှု သတိပေးချက်: CSRF Token မမှန်ကန်ပါ!");
      }
      echo "တရားဝင် Form ပေးပို့မှု ဖြစ်ပါသည်။";
  }
  ?>
  <!-- Form တွင် ထည့်သွင်းပုံ -->
  <form method="POST">
      <input type="hidden" name="csrf_token" value="<?= generateCsrfToken() ?>">

          ];
          http_response_code(200);
          echo json_encode(["status" => "success", "data" => $users]);
          break;

      case "POST":
          $input = json_decode(file_get_contents("php://input"), true);
          if (empty($input["name"])) {
              http_response_code(422);
              echo json_encode(["status" => "error", "message" => "Name is required"]);
              exit;
          }
          http_response_code(201);
          echo json_encode(["status" => "created", "data" => $input]);
          break;

      default:
          http_response_code(405);
          echo json_encode(["status" => "error", "message" => "Method Not Allowed"]);
          break;
  }
  ```

#### 🔹 Module 12: MVC Architecture & Capstone Project
- **သင်ယူမှု ရည်ရွယ်ချက် (Objective)**: လုပ်ငန်းခွင်သုံး Enterprise စနစ်များ၏ Model-View-Controller ဖွဲ့စည်းပုံကို အစမှအဆုံး ကိုယ်တိုင်ရေးဆွဲ တည်ဆောက်နိုင်ရန်။
- **စနစ်ဖွဲ့စည်းပုံ (Directory Structure)**:
  ```
  my-mvc-project/
  ├── app/
  │   ├── Controllers/       # User request များကို လက်ခံထိန်းချုပ်သောနေရာ
  │   │   └── ProductController.php
  │   ├── Models/            # Database Query များနှင့် Data logic များ
  │   │   └── Product.php
  │   └── Views/             # အသုံးပြုသူမြင်ရမည့် HTML/Blade ပုံစံများ
  │       └── products/
  │           └── index.php
  ├── config/
  │   └── database.php
  ├── public/                # Web Server Document Root (လုံခြုံရေးအရ ဤနေရာသာ Public ပေးရမည်)
  │   ├── index.php          # Front Controller (Single Entry Point)
  │   └── css/style.css
  ├── vendor/                # Composer packages
  └── composer.json
  ```
- **MVC လုပ်ဆောင်ချက် အကျဉ်းချုပ်**:
  1. `public/index.php` မှ Request အားလုံးကို လက်ခံသည်။
  2. သက်ဆိုင်ရာ `ProductController` သို့ လွှဲပြောင်းပေးသည်။
  3. Controller သည် `Product` Model ထံမှ Database Data ကို တောင်းယူသည်။
  4. ရရှိလာသော Data ကို `Views/products/index.php` တွင် ထည့်သွင်းကာ Browser သို့ Render ပြုလုပ်ပေးသည်။
