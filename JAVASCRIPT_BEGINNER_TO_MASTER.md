## 📌 မိတ်ဆက် (Course Overview)

ဤလမ်းညွှန်သည် **JavaScript** ကို အခြေခံ (Beginner) မှစ၍ လုပ်ငန်းခွင်တွင် တကယ့် Software Engineer / Frontend / Fullstack Developer တစ်ဦးအဖြစ် ရပ်တည်နိုင်သည်အထိ (Master Level) အသေးစိတ် အဆင့်ဆင့် နားလည်လွယ်သော မြန်မာဘာသာဖြင့် စနစ်တကျ ရေးသားထားသော လက်စွဲစာအုပ် ဖြစ်ပါသည်။

ခေတ်ဟောင်း JS ရေးနည်းများ မဟုတ်ဘဲ **Modern ES6+ (ES2015 မှ ES2024+ အထိ)** အသစ်ဆုံး စံနှုန်းများ၊ Browser Runtime Architecture (V8 Engine, Event Loop, Microtask Queue)၊ Asynchronous Programming (Promises, Async/Await)၊ DOM Manipulation & Event Delegation၊ REST API Integration၊ Performance Optimization နှင့် Web Security (XSS ကာကွယ်ခြင်း) တို့ကို လက်တွေ့လုပ်ငန်းခွင် နမူနာ ကုဒ်များနှင့်တကွ ထည့်သွင်း ရှင်းလင်းထားပါသည်။

## 💡 JavaScript ရေးသားရာတွင် မဖြစ်မနေ သိထားသင့်သော ရွှေစည်းမျဉ်းများ (Gold Rules)

1. **`var` ကို လုံးဝ မသုံးပါနှင့်**: ပြောင်းလဲမည့် Value ဖြစ်ပါက `let` ကိုသုံးပါ၊ ပြန်မပြောင်းလဲမည့် Value / Reference ဖြစ်ပါက အမြဲတမ်း `const` ကို ဦးစားပေး သုံးပါ။
2. **`==` အစား `===` (Strict Equality) ကိုသာ အမြဲသုံးပါ**: Type Coercion ကြောင့် မလိုလားအပ်သော Bug များ မဖြစ်ပေါ်စေရန် ဖြစ်သည်။
3. **Array Mutation ကို သတိပြုပါ**: မူရင်း Array ကို တိုက်ရိုက် ပြောင်းလဲဖျက်ဆီးတတ်သော `push`, `splice`, `reverse`, `sort` တို့အစား Pure Functional ချဉ်းကပ်မှုဖြစ်သော `map`, `filter`, `toSorted`, `toSpliced` သို့မဟုတ် Spread `[...arr]` ကို အသုံးပြုပါ။
4. **DOM Event Listener များတွင် Event Delegation ကို ဦးစားပေးပါ**: List Items အခု ၁,၀၀၀ ရှိပါက Listener အခု ၁,၀၀၀ မထည့်ဘဲ Parent တစ်ခုတည်းတွင် Event Delegation ပြုလုပ်ပါ။
5. **Async Code များတွင် `try...catch` မပျက်မကွက် သုံးပါ**: အထူးသဖြင့် Network Request (Fetch) များတွင် Network Error သို့မဟုတ် Response Parsing Error များကို User ထံ အဆင်ပြေစွာ ပြသနိုင်စေရန် ဖြစ်သည်။
